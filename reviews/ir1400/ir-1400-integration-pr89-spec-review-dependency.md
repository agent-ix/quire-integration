## Dependency classification and order

FR-526 is upstream enablement for immutable issued carrier, subject/support and flat ledger authority. The published current QSL API precedes integration consumption, which precedes IT-022 qualification. The actual edge is QSL FR-526 -> integration IT-022; FR-526 references its own FR-516 without depending back on IT-022. The changed edge introduces no cycle. Current owner publication is present in the normal main lock; no compatibility shim, pin or copied owner implementation supplies enablement. The IT remains a qualification artifact, not a duplicate owning requirement. Upstream FR-350 contract synchronization remains separate and open as cited above.
