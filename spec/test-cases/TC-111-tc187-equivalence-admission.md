# TC-111: Qualify public TC-187 U37 equivalence admission

## Description

Exercise every U37 equivalence admission alternative through public native model
intake and package assembly. Bind the original public vector by reference through
`vectors_of(TestCase::Tc187)`. Original minimal R/F model documents declare real
Time/Length roots and derived Speed, R's Area, and F's affine local unit. These
inputs are domain documents, never reconstructed checked packages or receipts.

## Test Procedure

1. Parse original complete-profile source, build forms, admit selected original
   model documents, and assemble without requiring unrelated body checking.
2. Cover imported/imported and imported/local pairs, missing aliases, dimensions
   and ratio units, self pairs, duplicate pairs in both orientations and with
   equal and differing ratios, wrong-dimension units, zero/negative ratios,
   imported composed affine offset, and Time versus Area.
3. Exercise Dur without its base authority and with that authority before and
   after the derived pair. Exercise both Speed ratios without authorities, with
   either authority omitted, and with both authorities in both orders and on
   either side of the derived pair.
4. Exercise consistent and inconsistent ABC cycles in literal forward and reverse
   source order. Assert the actual closing declaration and complete original
   retained declaration sequence, including exact spans.
5. Compare full typed refusal causes, codes and primary spans. Acquire retained
   dimension keys from genuine successful alias-unit controls, separately from
   admitted model scalar dimension keys. For successes assert exact original
   row order/spans, owner package, canonical native dimension pairs, rational
   scales, least class roots and exact relative sizes.

## Expected Results

The new equivalence admission target must satisfy all authored U37 alternatives.
Model intake must succeed even for affine-unit cases; an intake error is a setup
failure, never an accepted equivalence refusal. Duplicate and inconsistent cycle
refusals preserve actual source order and the last closing primary locus. Derived
pairs use complete base authority independent of source phase ordering.

This is admission-only evidence. It establishes no generated-oracle agreement,
value/accounting comparison, whole SC-04 completion, or IR-842 closure. Any real
owner disagreement remains a failing receipt with its exact typed facts.
