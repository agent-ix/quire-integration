# TC-104: Execute equality generators against independent public QSL authority

## Description

Refine IT-019-SC-05 with actual FR-021 whole-function Equal/NotEqual over
Boolean, bounded Integer, tuple, record and union inputs, and distinct FR-018
operation-generator observations over closed literal bodies. Each entry point
receives only its own measured credit; full family completion remains Planned.

## Test Procedure

1. Author ten pure equality functions and ten separate exercise calls.
   Acquire the original source through QSL, strictly admit its emission, and
   select actual declaration, body, call, argument and scalar type handles.
   Lower the actual requested roots and authenticate the contract against its
   source. Generate public CompositeEquality Equal and NotEqual declarations
   with the real Boolean result type and source parameter descriptors.
2. Compile and invoke the returned actual native symbols. Independently
   reacquire the same source into an unregistered FR-485 registry. Compare
   the complete Evaluation or CallFailure, result location, ordered located
   losses, admitted charges and every consumed counter with identical fresh
   global allowances at work 0, 1 and 1024. Do not subtract, precharge,
   reconstruct outcomes or install generated factories into the authority.
3. Require independent Boolean truth tables for all four Boolean pairs and
   explicit equal, less and greater Integer examples. Successful calls have
   the required Boolean and no location or loss. Work 0 must stop at
   FunctionCall; work 1 must stop at EqualityPlanForm after exactly the outer
   FunctionCall. Stops retain the source body origin, WorkUnits allowance,
   consumed work and next charge 1 for FunctionCall. EqualityPlanForm's next
   charge is 2 for primitives and nullary union values, 6 for the Boolean pair
   tuple and 4 for the single-field Boolean record. Every other counter is zero.
4. Compare actual argument arity and kind refusals, including combined invalid
   count/kind precedence, with zero charges and counters. For Integer inputs
   require the actual Int[0,9] source bound to refuse Integer 10. Independently
   check and admit a changed valid source, require its original owner refusal
   before charges, then execute the original healthy symbols.
5. Keep deeper nominal closures, alternate union payloads and per-form
   operational boundaries Planned under IR-842 until their own actual source
   cohorts and complete observations exist. Whole-function nominal rows use
   FR-485 sessions and have no dependency on operation-only binding support.

6. Separately qualify the public FR-018 composite equality generator for
   closed Boolean literal Equal/NotEqual truth tables and Integer equal,
   less and greater literal pairs. Derive operand semantic types and expression
   IDs from original QSL emission, authenticate actual lowered contract bytes,
   and invoke returned native environment/oracle symbols. Evaluate each same
   source body through a fresh independently checked public QSL evaluator.
   Compare complete typed outcome, all losses, ordered charges and all counters
   at work 0, 1 and 1024 without constructor-charge subtraction. Independently
   require explicit Boolean answers and exact EqualityPlanForm stops (next
   charge 2 and zero consumed work). Keep nominal shapes and conversions Planned
   until their own actual complete public observations exist.

7. Add original tuple Pair(Boolean, Boolean), record Flag { flag: Boolean; }
   and union Choice { First, Second } declarations with Equal/NotEqual functions
   and separate exercise calls. Obtain authentic argument Values by running
   independently selected closed source constructor functions through public
   FR-485 sessions. These completed Values are external inputs to fresh whole
   equality calls; constructor meters are never reused or subtracted. Require
   explicit equal/different Boolean answers and the same full whole-call
   observations. Actual nominal parameter descriptors come from the emitted
   parameter nodes. No fabricated owner key, TypeEnvironment or copied renderer
   assembly is permitted.
8. Measure equality descriptor result mismatch, requested unsupported
   capability, parameter-kind mismatch, argument-count mismatch, duplicate
   requests, ambiguous names, duplicate declaring nodes and wrong actual call occurrence through
   public generation. Each retains a typed refusal and a healthy generated
   sibling. Measure Scalar Negate using an actual source unary body and its
   actual call occurrence; retain the observed unsupported disposition without
   granting execution credit.

## Expected Results

`generated_oracle_family_function_equality::primitive_and_nominal_function_equality_matches_fresh_qsl_sessions`
passes 78 whole-call comparisons, 32 input refusals and ten changed-owner
refusals. Each work stop and completed Boolean has an independent required
shape, and both sides compare full typed outcome, location, located loss,
ordered admitted charges and every counter. The original QSL constructors
supply external nominal input Values; their separate session meters contribute
nothing to the compared equality calls. The same test observes eight typed
generation-boundary refusals, each retaining a healthy nominal sibling, and
actual unary Scalar Negate's UnsupportedOperator with sibling isolation.

`generated_oracle_family_function_equality::primitive_composite_generator_matches_independent_checked_bodies`
passes 24 FR-018 Boolean operation observations: both operators and all four
truth pairs at work 0, 1 and 1024. Six closed nonnegative Integer literal
candidates check and emit, but the generator retains OperandTypeMismatch at
position 0, with the actual emitted Integer type expected and no found type.
Their operands are inline typed Literal terms; the public source operand
confirmation route does not admit them as reference-backed occurrences. These
six are measured nonexecuted dispositions with healthy Boolean siblings in the
same request, never Boolean agreement credit. Integer native agreement remains
Planned under IR-842 pending a genuine supported original-source operand route.
