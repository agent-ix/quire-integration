# TC-104: Execute primitive whole-function equality against fresh QSL sessions

## Description

Refine IT-019-SC-05 with Equal and NotEqual whole-function generation over
Boolean and bounded Integer parameters. This is FR-021 evidence; it supplies
no FR-018 raw equality-oracle credit.

## Test Procedure

1. Author four pure equality functions and four separate exercise calls.
   Acquire the original source through QSL, strictly admit its emission, and
   select actual declaration, body, call, argument and scalar type handles.
   Lower the actual requested roots and authenticate the contract against its
   source. Generate public CompositeEquality Equal and NotEqual declarations
   with the real Boolean result type and source parameter descriptors.
2. Compile and invoke the returned actual native symbols. Independently
   reacquire the same source into an unregistered FR-485 registry. Compare
   the complete Evaluation or CallFailure, result location, ordered located
   losses, admitted charges and every consumed counter with identical fresh
   global allowances at work 0, 1 and 1024. Do not subtract, precharge,
   reconstruct outcomes or install generated factories into the authority.
3. Require independent Boolean truth tables for all four Boolean pairs and
   explicit equal, less and greater Integer examples. Successful calls have
   the required Boolean and no location or loss. Work 0 must stop at
   FunctionCall; work 1 must stop at EqualityPlanForm after exactly the outer
   FunctionCall. Stops retain the source body origin, WorkUnits allowance,
   consumed work and next charge 1, with every other counter zero.
4. Compare actual argument arity and kind refusals, including combined invalid
   count/kind precedence, with zero charges and counters. For Integer inputs
   require the actual Int[0,9] source bound to refuse Integer 10. Independently
   check and admit a changed valid source, require its original owner refusal
   before charges, then execute the original healthy symbols.
5. Keep record, tuple and union CompositeEquality rows Planned under IR-842
   until actual source cohorts, authentic lowering, native generation and
   independent complete observations exist. Result, capability, occurrence,
   duplicate/ambiguous selection and mixed refused-sibling boundaries also
   remain Planned until their specific public routes are exercised. Scalar
   Negate requires an actual typed unsupported-generation observation.

## Expected Results

The four primitive operation rows require 42 complete whole-call envelope
comparisons, independent Boolean outcomes and exact work stops, plus source
owner and argument refusals. Pending execution, these rows are Planned. Only
measured native rows may become Passed. Full FR-021 and SC-05 remain Planned;
this procedure supplies neither FR-018 credit nor whole-family closure.
