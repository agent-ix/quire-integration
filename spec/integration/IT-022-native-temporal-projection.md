# IT-022: Project admitted native temporal inputs through genuine TL owners

## Objective

Construct the FR-350 projection inputs without running either evaluator. A
successful `project_tl` returns a constructor-private value retaining genuine
TL formula, proposition-map, trace or position-history, and request reader
outputs. It retains the original native facts and independent observation-owner
views. A failed premise returns a typed non-value and no partial projection.
Strict bridge correspondence readers and result joins are separate obligations;
this integration does not report them complete.

## Target Integration

Original QSL source and model evidence → QSL emitter → strict IR reader →
checked subject, owner-bound classification and admitted native valuation rows →
IT-020 formula constructor → actual TL proposition, trace/history and request
constructors and strict readers. The native subject name comes from the selected
authored occurrence. The request's correspondence name is the public bridge
profile `quire.native-temporal-correspondence/v1`, not a computed identity.

## Preconditions

The classification retains the actual owner-issued checked-package admission
binding. Before using its facts, `validate_mapping_binding` requires the supplied
package to retain that binding, requires the subject's package membership, and
compares the complete value with owner reclassification under the same surrounding
closure. Independent equal-content admissions do not exchange classifications;
clones retaining the original owner admission can supply a newly read subject.

The bridge consumes QSL `ValuationEvidence` and its ordered rows as admitted input
facts, not as an attestation of a separate observation producer or package
admission. It checks each row against the selected occurrence, trace position,
anchor, immutable capture instance and selected observation revision. Agreeing
duplicate rows remain distinct owner rows and are rejected as duplicate projection
cells; the bridge never calls `value_of` to erase them. A Boolean false is present
data. No absent, conflicting or evicted fact becomes false.

## Inputs

`project_tl` takes the actual checked package and subject, QSL classification,
surrounding closure, native trace and valuation evidence for one declared
occurrence, actual admitted observation revision, and independent TL/QObs owner
selections and limits. Selection structs group references to real owner values;
they do not replace their records, assert trust, or supply an evaluator callback.

## Test Procedure

1. IT-022-SC-01: Emit original source once and admit the bytes twice. Require a
   local subject and local classification to pass; substitute only the foreign
   classification while keeping the local subject and require a named admission
   refusal before formula construction. A newly read subject on a package clone
   retaining the same admission is accepted, including after moving the package.
   Preserve the existing foreign-subject and altered support/definition/closure
   controls.
2. IT-022-SC-02: Admit native rows through `ValuationEvidence::admit`. Construct
   every required position/proposition value from these rows, checking the exact
   occurrence, anchor, capture instance, revision and checked operand. Compare
   true and explicit false cells in actual admitted TL owner values. Remove a
   cell for incompleteness; duplicate an agreeing row, swap its operand or
   position, or foreign-bind the occurrence/revision for refusal. Repeated formula
   uses retain the source relation and do not excuse duplicate input cells.
3. IT-022-SC-03: Construct closed and prefix future requests, and individually
   supported bounded-past requests with complete origin history. Preserve the
   surrounding target independently of decision closure. A history cutoff is
   incomplete, not a new origin. Unsupported classifications retain every
   original dimension and yield no projection. A named native occurrence selects
   the exact authored subject name even when declarations share a checked node.
4. IT-022-SC-04: Retain fixed-sample epoch, period and unit as actual owner data.
   Refuse a changed clock or event-count reinterpretation. Missing samples are
   incomplete. If an owner cannot represent an otherwise authored supported
   selection, preserve its typed refusal and record the exact upstream limitation;
   do not narrow FR-350, invent a conversion or copy an owner record.
5. IT-022-SC-05: Supply independent admitted clock, decision and surrounding
   progress/closure, completeness and availability views. Check native bindings
   against those values and pass the genuine views to the request owner. Derive
   and strict-read the request, retaining the exact admitted output with its
   source formula/map/trace/history. No evaluator or result reader is invoked.
6. IT-022-SC-06: Precharge bridge node, position and cell visits and reject before
   processing a first excess unit. Bound each generated record with its caller
   byte ceiling using the owner producer's bounded writer. Check actual operations
   exactly at their measured bound and one less, with all other settings above
   their measured counts; verify fresh counters and no returned partial value.
   QSL view/classifier work remains excluded under the owner default. Owner
   readers keep their independently supplied finite limits. Support and cause
   counters belong to the later join and are not qualified by projection tests.

## Expected Results

Reachable projection cases return actual immutable owner-admitted artifacts and
preserve their native correspondence inputs. Every failed premise is a typed
unsupported, incomplete or refused result without a successful partial value.
The integration preserves current owner limitations as limitations, not successful
FR-350 evidence. Full correspondence reading, result joining, supersession and
complete seven-counter qualification remain open under IR-1005.
