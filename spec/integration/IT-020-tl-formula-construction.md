# IT-020: Construct a bounded TL owner formula from checked occurrences

## Objective

Qualify the formula construction component of FR-350. This component is not a
validated projection and discharges no runtime totality, observation, history,
valuation, correspondence or result-join premise.

## Target Integration

Authored QSL source → real checked-package emitter → strict IR admission → QSL
subject and classification → `construct_tl_formula` → actual TL FormulaDocument
constructor, canonical encoding and strict owner reader. Neither evaluator runs.

## Preconditions

The subject belongs to the actual supplied package instance and its supplied
classification equals complete owner reclassification under the supplied surrounding
closure, checked through `validate_mapping_binding`. Owner view construction,
reclassification and predicate validation have owner limits but no component work
receipt: their internal visits are explicitly excluded from component work claims.

## Inputs

The public component accepts package, borrowed subject, classification, surrounding
closure and `TlFormulaLimits`. Its successful value retains the original classification,
actual owner formula and canonical bytes, and ordered original checked predicate
handles associated with their TL proposition occurrences. Static Boolean admission
is not runtime totality. Unsupported classifications retain every owner dimension.
For event-position and fixed-sample false-extension source, QSL requires a closed
interval: `eventually holds(true)` returns native `TemporalCause::MissingInterval`
before any checked package, subject, classification or component exists. Infinite-trace
unbounded source can reach a checked subject but retains its genuine owner Unsupported
classification without a formula. No Supported-unbounded premise API is promised by
this component. Bounded endpoints outside the owner's u32 range
return a typed representability refusal.

   exact operator/operand/interval rows and strict owner-read equality.
2. IT-020-SC-02: Reject a foreign instance or altered classification before formula
   construction. Retain Unsupported dimensions unchanged and original outstanding

   Under each false-extension profile, unbounded source retains the native
   MissingInterval refusal before emission; infinite-trace unbounded source retains
   its owner Unsupported classification and emits no component.
3. IT-020-SC-03: Charge each component graph-entry scheduling visit and each emission
